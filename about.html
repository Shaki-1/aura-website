What is AURA?

Local-first assistant

AURA is a local-first Windows accessibility assistant for adapting visual support directly on your desktop.

Desktop support

It is designed around everyday Windows use, helping make active interfaces clearer and more comfortable.

Personal profiles

AURA lets users choose the support profile that best matches how they see and work.

Accessibility modes

Color Blind

Strengthens visual separation and reduces reliance on color alone.

Eye Strain

Supports softer, more comfortable viewing during longer sessions.

Low Vision

Helps make reading areas, focus, and important interface elements easier to notice.

Privacy-first design

No screenshot uploads

AURA does not upload screenshots.

Local processing

Accessibility support is designed to happen on the user's computer whenever possible.

Private by default

AURA is built around the idea that accessibility should not require giving away personal information.
