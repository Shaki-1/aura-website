What AURA does

Improves visual comfort

AURA supports clearer, calmer desktop use by adapting visual assistance for common accessibility needs.

Runs locally

The assistant is designed around local processing on Windows, without uploading screenshots to a remote service.

Keeps users in control

Users choose the support profile and decide when accessibility assistance should be active.

Accessibility profiles

Color Blind

Helps reduce dependence on color alone with clearer separation and stronger visual cues.

Eye Strain

Supports a more comfortable viewing experience for longer sessions and visually intense work.

Low Vision

Emphasizes focus, readability, and interface visibility so important content is easier to locate.

Local-first privacy

No screenshot uploads

AURA is designed so accessibility support does not require uploading screenshots.

No screenshot storage

The demo is built around privacy-first behavior and does not store screenshots as part of its support model.

Local processing principle

Whenever possible, analysis and support should happen on the user's computer instead of elsewhere.

Policy and legal information

GDPR-friendly direction

AURA follows a local-first design direction intended to reduce unnecessary data sharing and support privacy-conscious use.

User-controlled support

Accessibility support is user-controlled. Users decide which profile to use and when to rely on the assistant.

Demo software status

AURA App v0.3.0 is demo software for accessibility research, learning, and product exploration.

License and usage note

This project is provided for educational accessibility research and learning purposes.

Privacy-first principle

The product direction is to make accessibility assistance useful without requiring sensitive visual data to leave the device.

Experimental detection

Windows UI Automation detection is experimental and may change as the demo becomes more reliable.
