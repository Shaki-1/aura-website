# AURA Website

AURA Website is the public landing page for AURA, a local-first Windows accessibility assistant designed to support more comfortable and accessible desktop use.

## Website

https://shaki-1.github.io/aura-website/

## About AURA

AURA is a local-first accessibility assistant for Windows desktop users. It is designed to provide visual support directly on the user's computer while keeping privacy at the center of the experience.

AURA includes support for:

- Color Blind profile for clearer visual separation and reduced reliance on color alone
- Eye Strain profile for softer, more comfortable viewing during longer sessions
- Low Vision profile for stronger visibility, focus, and reading support
- Privacy-first design built around local processing
- No screenshot uploads
- Windows desktop application workflows

## Privacy

The website itself does not collect user data. AURA is designed around local processing so accessibility support can happen on the user's computer whenever possible, without uploading screenshots.
